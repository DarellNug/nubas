# Repositori Tugas & Proyek Sekolah (`nubas`)

Selamat datang di repositori **nubas**!

## 📌 Tujuan Utama

Tujuan utama dari repositori ini adalah untuk **mengorganisasi, menyusun draft, dan menyimpan seluruh proyek serta tugas sekolah ke GitHub**. Dengan menggunakan repositori ini, semua berkas proyek dapat tersimpan dengan rapi, teratur, dan mudah diakses tanpa berantakan di berbagai perangkat (laptop/PC).

---

## 📂 Struktur Repositori

Repositori ini dikelompokkan berdasarkan tingkat kelas dan mata pelajaran:

```text
nubas/
├── 11/                     # Proyek & Tugas Kelas 11
│   ├── PBO/                # Pemrograman Berorientasi Objek
│   ├── PGIM/               # Pemrograman GIM
│   └── PWeb/               # Pemrograman Web
├── XII/                    # Proyek & Tugas Kelas 12 (XII)
│   └── UKInternalFlutter/  # Uji Kompetensi / Assessment Internal Flutter
└── README.md               # Dokumentasi repositori
```

---

## 🚀 Manfaat & Fungsi

- 🔄 **Sinkronisasi Antar Perangkat**: Memudahkan pengerjaan tugas dari perangkat mana saja tanpa takut berkas tercecer.
- 🗂️ **Penyimpanan Terstruktur**: Mencegah berkas berantakan dengan membagi folder berdasarkan kelas dan mata pelajaran.
- 📜 **Kontrol Versi**: Memantau riwayat pengerjaan, draft, serta hasil akhir tugas sekolah.
