Panduan Flashing Custom ROM (LineageOS)

Prosedur instalasi sistem operasi kustom untuk perangkat Android Anda.

Fase 1: Persiapan (Yang Anda Butuhkan)

  • Baterai HP: Pastikan terisi minimal 50%.
  • PC/Laptop: Siapkan folder file ROM (LineageOS) dan file TWRP.
  • Odin (Flashing Tool): Unduh versi 3.14.4 dan ekstrak di PC.
  • Samsung USB Drivers: Instal di PC agar HP dapat terdeteksi.

Fase 2: Unlock Bootloader

  • Aktifkan Opsi Pengembang (Ketuk "Build number" 7x di Pengaturan > Tentang ponsel).
  • Buka Opsi Pengembang: Aktifkan "OEM unlocking" dan "USB debugging".
  • Matikan HP. Tahan tombol Volume Atas + Bawah bersamaan, lalu colok kabel USB ke PC.
  • Di layar peringatan (biru/hijau), lepas tombol. Tahan Volume Atas 5 detik untuk masuk "Device unlock mode".
  • Tekan Volume Atas 1x untuk konfirmasi. HP akan terformat dan UBL selesai! (Lewati semua setup awal Android).

Fase 3: Flash TWRP Recovery

  • Masuk Download Mode: Matikan HP, tahan Vol Atas + Bawah, colok USB ke PC, tekan Vol Atas 1x.
  • Buka Odin3 v3.14.4.exe di PC. Pastikan ada kotak biru di bawah "ID:COM".
  • PENTING: Di tab "Options" Odin, hilangkan centang pada "Auto Reboot".
  • Klik tombol "AP", masukkan file twrp-3.7.1.img.tar.
  • Klik "Start". Tunggu sampai muncul notifikasi "PASS!" berwarna hijau.

Fase 4: Masuk TWRP & Format Data

  • Paksa Restart dari layar Download: Tahan Vol Bawah + Power selama ~7 detik.
  • Tepat saat layar mati, langsung ganti tahan Vol Atas + Power sampai logo TWRP muncul.
  • Di menu TWRP, pilih "Wipe" > "Format Data".
  • Ketik yes lalu tekan centang (untuk membuka enkripsi penyimpanan).
  • Kembali ke menu utama, pilih "Reboot" > "Recovery". (HP akan masuk kembali ke TWRP).

Fase 5: Instalasi LineageOS

  • Saat di TWRP, pastikan HP terhubung ke PC. Buka File Explorer PC (HP akan terbaca sebagai USB drive).
  • Copy file .zip LineageOS dari PC ke Internal Storage HP.
  • Di layar TWRP, pilih menu "Install".
  • Cari dan pilih file .zip LineageOS yang baru saja disalin.
  • Geser (Swipe to confirm Flash) di bagian bawah layar.
  • Tunggu proses selesai. Jika sudah "Successful", ketuk "Reboot System". Selesai!
